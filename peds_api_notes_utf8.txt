PEDSPOS Integration Notes
This note gives you a brief understanding of the different options we provide to integrate with PEDSPOS system. The third party system can use any of the three integration options. The options are:1) Shared Folder 2) SOAP 3) REST API
1) Shared Folder This type of integration uses a shared folder that will be available to both applications. The third party application drops the invoice in to the shared folder and PEDSPOS will pick from there.
Pros  Easy to integrate  requires a minimum effort to communicate
Cons  one-way communication  security issues
2) SOAP This type of integration uses Simple Object Access Protocol (SOAP). The SOAP is a standard objects to consume web service and XML used to format the data.
Web Service Definition Language (WSDL) http://localhost:2010/PEDS/api/HoldSalesService?WSDL
Pros  two-way communication  better security
Cons  requires more effort to communicate  heavy data
